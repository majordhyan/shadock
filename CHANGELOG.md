# Changelog

## 1.0.0 (Minecraft 26.3)

First release.

- Press H to open the dock in the bottom-left corner. Click a pack to switch to it.
- Drag packs into whatever order you want. The order is saved. There's also an A-Z mode, where dragging is off.
- The + button imports a shader zip through your system's file picker. It checks that the zip is actually a shader pack, and asks what to do if the name is already taken.
- Arrow keys and Enter work, and 1-9 switch to that row directly.
- A settings screen for sort mode, auto-hide, animation and duplicate handling.
- Needs Iris 1.11.7 and Fabric API. Client only.

H instead of O because 26.3 uses O for the Friends list.
